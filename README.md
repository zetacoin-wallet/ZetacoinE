## Why Zetacoin Wallet

Zetacoin has produced a block every 30 seconds since 2013, through a move from SHA-256 to Scrypt and a one-for-one swap from the old chain in 2021. What ships today is the client for that chain: a wallet, a node, a staking client and a miner in one application.

You do not need this repository to use the wallet. It is here for the record and for anyone who wants to read the code behind the build, and the packaged installers remain the supported route on every platform.

- Keys stay local in `wallet.dat`, encrypted with a passphrase only you know.
- The node validates the chain itself, so balances come from the network, not a dashboard.
- Staking pays a fixed 0.0625 ZET per coinstake block and needs no minimum.
- Windows, macOS and Linux builds ship from one release, with published checksums.

This repository is the source tree the desktop builds are produced from.
